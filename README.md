# Zoo Escape

A keyboard-controlled 3D isometric zoo game built with Three.js. Calm escaped animals, leash them and walk them home before the Zoo Panic meter hits 100%.

- Two levels plus a daily shift with streaks
- Combo scoring, random events and a golden bonus
- Animal album, zoo shop and unlockable zookeepers

## Play

Open `index.html` in a browser, or visit the deployed site.

Controls: WASD or arrows to move, Shift to run, Space to calm, Q for binoculars (Level 2), E for the whistle, R to retry, Esc to pause, M for sound.

## Deploy

This is a static site with no build step. Vercel serves `index.html` as-is.
